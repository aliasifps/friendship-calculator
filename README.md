# Amity & Kin — The Importance of Friendship & Interactive Calculator 💖

An ultra-modern, responsive single-page web experience celebrating the beauty, scientific benefits, and lifelong value of true friendship.

![Amity & Kin](https://images.unsplash.com/photo-1529156069898-49953e39b3ac?auto=format&fit=crop&w=1200&q=80)

## ✨ Key Features

- 🔮 **Cosmic Friendship Calculator (Hero Section)**:
  - Calculate friendship synergy percentage with animated SVG progress rings.
  - Trait Breakdown: Loyalty & Trust, Chaos & Laughter Quotient, 2 AM Telepathy.
  - Celebratory confetti particle explosion.
- 🛡️ **The 4 Pillars of Friendship**:
  - Unconditional Acceptance, Shared Joy, Mutual Growth, and Longevity & Well-being.
- 📸 **Curated Moments Gallery**:
  - Direct high-resolution photography from Unsplash.
  - Interactive category filters (Adventures, Cozy Chats, Golden Hour, Celebrations) with a full-screen Lightbox viewer.
- 📜 **Wisdom & Quote Engine**:
  - Timeless insights on friendship from thinkers, philosophers, and storytellers.
  - One-click copy-to-clipboard functionality.
- 🎨 **Digital Friendship Card & Certificate Studio**:
  - Real-time interactive card customizer (Recipient, Sender, Custom Message, Badge).
  - 4 radiant themes (Sunset, Ocean, Aurora, Rose Gold).
  - Direct HD image (.png) export powered by HTML5 Canvas.
- 💡 **Friendship Masterclass & Pledge**:
  - Practical tips to nurture lifelong bonds and an interactive friendship oath.

## 🚀 Live Demo & Usage

Simply open `index.html` in any modern web browser or serve with a local development server:

```bash
# Using Python
python -m http.server 8080

# Or with Node.js
npx serve .
```
